## 3. PROMPT DETERMINISTA DSL DAG SHERIFF V8 (`PROMPT_DSL_DAG_SHERIFF_V8.md`)

El prompt que Mavis ejecuta en modo loops, en orden DAG:

```
1. READ_LITERAL_INPUT_BLOCK
   - Leo el mensaje de Max sin reinterpretar
   - Lo copio a GitHub en archivo INPUT_BLOCK_NNN_<descripcion>.md
   - Commit inmediato con hash anotado

2. CHECK_GAP
   - ¿Hay gap entre spec y código?
   - Si sí → INVESTIGATE_200_VECES (no escalar)
   - Si no → CONTINUE

3. INVESTIGATE
   - 10 búsquedas comunidad devs mínimo
   - 1 archivo INVESTIGACION_*.md con hallazgos
   - 1 commit con el archivo

4. HYPOTHESIZE
   - 25 hipótesis de uso (7 grupos: A onboarding / B bandeja / C chat /
     D docs / E memoria / F config / G status)
   - 1 archivo HIPOTESIS_USO_25.md
   - 1 commit

5. SIMULATE
   - 25 simulaciones de uso (1ra pasada) → 76% REFUTADAS típico
   - 25 simulaciones de diseño → 84% CAMBIAR típico
   - 2 archivos SIMULACIONES_*.md
   - 2 commits

6. REFUTATION
   - 10 refutaciones (defectos/mejoras/faltantes)
   - 1 archivo REFUTACIONES_10.md
   - 1 commit

7. EXPERT_PANEL
   - 10 paneles de experto (UX, Design Systems, Backend, MCP,
     Multi-Agent, Graphiti, Observabilidad, Search, DevOps, A11y)
   - 40 findings priorizados
   - 1 archivo PANELES_EXPERTO_10.md
   - 1 commit

8. APPLY_DESIGN
   - 1 prototipo HTML estático con 5 zonas fijas
   - 8 screenshots evidencia (Playwright)
   - 1 commit

9. AUDIT
   - Auditoría del prototipo contra 10 docs
   - Score honesto (ej. 57%)
   - 1 archivo AUDITORIA_*.md
   - 1 commit

10. REDESIGN
    - Iteración con correcciones
    - 7 screenshots evidencia
    - 1 commit

11. BACKEND_IMPLEMENT
    - Si Fase 0 → kernel + 4 workflows + adapters
    - Si Fase 1 → OpenClaw con DSL 15 nodos

12. VERIFY_E2E
    - Smoke test con doc real
    - Screenshots del flujo
    - 1 commit

13. CERTIFY_OR_LOOP
    - Si TODO verde → CERTIFIED
    - Si hay gap → volver a paso 2
```
