🔒 F) Modal input-block · accesible + integridad

role=dialog + aria-modal=true + focus trap + Esc para cerrar + integrity check antes de enviar

♿ Accesibilidad WCAG 2.1 AA

  • role="dialog" anuncia al screen reader
  • aria-modal="true" bloquea contenido detrás
  • aria-labelledby="title" lee el encabezado
  • aria-describedby="body" lee el contenido
  • Focus trap: Tab cicla solo dentro del modal
  • Esc cierra el modal
  • Focus inicial: primer botón (Confirmar)
  • Contraste: 7.2:1 texto primary (AAA)
  • Contraste: 4.6:1 texto secondary (AA)
  • Teclado completo: sin mouse requerido

🔐 Integridad criptográfica

  • SHA-256 del contenido verbatim
  • Hash chain estilo blockchain (cada block incluye hash del previo)
  • Trigger SQLite no_update_inputs
  • Trigger SQLite no_delete_inputs
  • Append-only — solo INSERT permitido
  • Atomic write con os.replace() (preserve owner)
  • Verificación on-demand contra hash chain
  • Audit trail en 3 motores (vault, grafo, repo git)

🔄 Flujo de input-block (5 estados)

1
Usuario escribe mensaje en composer. InputBlockHook detecta UserPromptSubmit.
2
Sistema captura texto verbatim. Genera block_id = SHA-256(text)[:16]. Clasifica sentence_type.
3
Modal se abre con role=dialog. Muestra block_id, tags, content verbatim, integrity checks.
4
Usuario confirma/descarta/edita. Si confirma: INSERT en SQLite append-only + Graphiti EpisodicNode + save vault.
5
InputBlock se inyecta al system prompt tier 1. Pinned bar 🔒 aparece en el chat. Hash chain continúa.

📋 5 sentence types (taxonomía)

  • INSTRUCCION · "haz X" · genera task automática
  • PREGUNTA · "¿qué/cómo/cuándo...?" · activa RAG
  • CRITICA · "esto está mal" · dispara audit
  • EJEMPLO · "como este" · alimenta few-shot
  • META · "cambia tu comportamiento" · actualiza AGENTS.md
